# UE5 C++ Action RPG – Gameplay Code

C++ gameplay source for a third-person action RPG built in Unreal Engine 5.

> **Code only.** Assets, maps, and Blueprints are not included in this repository, so the project can't be opened or run from this repo alone. See the demo video for the game in action.

---

## About this project

I built this while following Stephen Ulibarri's Udemy course, *Unreal Engine 5 C++: The Ultimate Game Developer Course*, and then extended it with my own features (listed below). Credit for the original course design and teaching goes to the instructor.

## Features in the code

- Third-person character with melee combat
- Enemy AI with patrolling and attacking behavior
- Enemies that lock onto the player during attacks, using Motion Warping
- Health and stamina systems with on-screen bars
- Soul collection from defeated enemies
- Breakable objects that drop randomized items
